# Projeto para pesquisa de satisfação

## Sobre
Este projeto tem como objetivo repetir uma pesquisa de satisfação e retornar quantas vezes os clientes responderam "Excelente" e "Ruim".

## Código passo a passo
  Na parte inicial do código, são criadas listas para o nome, a idade e a resposta dos clientes. No processamento, a estrutura de repetição **for** é utilizada para repetir as pesquisas que entrarão para sua respectiva lista e, ao final, é informado a quantidade de excelentes e a quantidade de ruins.
